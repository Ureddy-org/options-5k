How to create the token (2 minutes)
  1. Open github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens, then Generate new token.
  2. Resource owner: pick the org that owns this repo. Repository access: Only select repositories → choose just this one.
  3. Under Permissions → Repository permissions, set Contents: Read and write. Nothing else is needed.
  4. Set an expiry you're comfortable with, generate, copy, and paste it above.
Scope it to this one repo with only Contents write. A token stored in a browser can be read by anything with access to that browser profile, so a narrow scope limits the damage if it leaks. Never paste a classic token with full repo scope here.

Capital at risk is maximum theoretical loss: net debit paid for debit structures, and width minus net credit for defined-risk credit structures. Undefined-risk positions require a manual figure. Assignment, early exercise, gap risk and pin risk can produce losses beyond these numbers, and multi-leg positions may not fill at the modelled net price. Figures assume each participant trades identical size from identical capital; your own fills, fees and tax treatment will differ. This is a bookkeeping tool, not risk management, and nothing here is a recommendation to trade.
